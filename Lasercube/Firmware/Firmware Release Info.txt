MK2 / PRO Firmware Release Info

v2-2 (18/10/26)

- 24 new visualizers, 197 in all: Halloween figures (a spider, a witch, a black cat, a vampire, a mummy and Thing, each in 2D and 3D, two bats, and Slimer from Ghostbusters), and nine new 3D dancers (Dancing Man, W2, MJ, Bear, W3, Alien, Bird, Elf and Santa)

- New keystone correction: when the cube projects onto a wall at an angle, Keystone H and Keystone V in Settings > Projection > Image Setup make the picture square again, with a Show Grid pattern to line it up

- Image Setup: every control now has its own icon, and Defaults also resets Zoom

- Web app image popup: all of the projection settings in tabs (Image, Colour, Safety and Test), with pads that show the picture as it lands on the wall, pinch to zoom and resize, and one Save button

- Web app Preview tab: watch the laser output live while you set size, position, keystone and safety zones from your phone

- Web app settings popup: Playlist / Visualizer (now with Fade Time), Audio with a live spectrum of what the cube hears, BPM with a beat display, Tap BPM and Sync Beat, and General

- The web app works better on phones and tablets: popups fit small screens and scroll, and sit centred on large ones

- Faster drawing: visualizers use around 17% less processor time, and full white now reaches full laser power

- The rotary encoder no longer skips or steps backwards when turned quickly

- A failed firmware upload from the web page now restarts into the previous firmware and tells you so

- LaserOS mode: the cube now reports its ID, output state and packet errors correctly to streaming apps, and ignores damaged packets

v2-1 (18/9/26)

- New multi-cube web UI: control every cube on the network from one browser tab, with an always-visible cube switcher, near-instant tab switching, live per-cube status, and auto-recovery after a cube reboots

- 6 new Halloween dancing figures - two pumpkins (a jack-o'-lantern on a vine, and a pumpkin-headed stick dancer), a ghost, a zombie, a dancing skull, and a full skeleton - each with a dozen-plus audio-reactive moves (spins, flips, head pops, patrols, collapses)

- New "Dancing W1" 3D dancer with 11 moves, including a leap, and idle breathing when the music goes quiet

- 82 more visualizers added (classic laserOS effects ported over, plus new originals like Tesseract, Galaxy Arms, Spiral Stair, Ocean Swell), bringing the total to 174

- Runtime network switching: change WiFi/Ethernet mode, IP settings, and WiFi credentials from the menu or web UI without rebooting the cube

- Real-time clock support added (PRO models only): on-device date & time, plus a laser diode usage odometer shown on the status page in hours

- Web UI polish: rounded card-based layout, WiFi status icon and channel shown in the header, faster reconnects, smoother playlist tile loading

- Effects now auto-enable with reset intensities on first web connection, without disturbing sliders already linked to MIDI

- Fixed a DHCP server crash on live network changes, an Art-Net unicast targeting bug, and an SD-card crash when removing the card during file browsing

- Numerous stability fixes across MIDI hotplug handling, playlist loading, and display/network stall recovery

v2-0 (14/08/26)

- New viz playlist player: create, edit and reorder your own playlists from the web UI
- New effects engine: 40+ projection effects (3D globe/spin/twist, jellyfish, flames, many audio-reactive) with live adjustment from the menu or web UI
- Menu now available in 12 languages, with extended fonts so non-ASCII names display correctly
- Web UI redesign: tile-grid playlist view, effects panel, better mobile support, more reliable connection
- 60+ new audio reactive laser visualizers added
- New 2D and 3D output preview: skip through vizzes/playlist cues with the encoder in 2D, rotate the viewpoint in 3D
- New animated boot logo, now showing the firmware version
- Status page additions: Cube IP address and temperature; WiFi status icon when in client mode
- Save indicator on the status bar whenever a setting is stored to internal flash
- Improved blanking/error handling for smoother output on all connection types
- Fixed missing green/blue colour on IDN mode with multiple scanners connected
- Faster audio FFT response with an optional higher visualizer update rate
- Smoother, more responsive ILDA playback when switching cues
- Improved cubes visualizer projection quality and audio reactivity

v1-20 (01/05/26)

* 42 audio reactive visualizers are now available (up from 29 in v1.19)
* IDN and ether-dream DAC modes added (* These are in Beta test)
* Fixed bug introduced in v1.19, which had LaserOS output horizontally mirrored.

v1-19 	(20/03/26)

* visualizer control mode now has 29 audio reactive visualisers (up from 3)
* Visualizer control mode now has a player which allows visualisers to be changed after a set delay period, shuffle option also added.
* Visualizer control mode now fades in/out during transition from one visualizer to another (this can be set in the new viz options menu).
* safety zone improvements to prevent potential beam leakage into safety zones with certain projections
* fixed occasional toggling of the charge indication icon on the LCD when the cube is running, and the charger is plugged in.
* Audio Gain now adjustable in 5dB increments (check current gain option as this may have changed due to this update!)


v1.18	(25/11/25)

* New Laser show player with category selection, and new media controls. APC MIDI mappings for each show within a selected category are now assigned automatically within the main APC grid (white / flashing red for selected). This requires the new MIDI mappings which are included in the latest SD card image located here: https://github.com/Wickedlasers/mk2SDContent

* New Playlist Web App, allowing playlist selection and control from any device with a web browser, in addition to controlling it from the LCD or APC MIDI device.

* Playlist Web App can use internal HTML or external HTML from the SD card, allowing user customisation of the Web App (see the v1.2 full user guide for more info).

* Playlist control mode can start projecting at power on (after interlock is enabled), or not depending on new playlist options menu.

* Network - Gateway IP is now disabled, so the MK2 does not appear as an internet capable device.

* Server IP address for WiFi and LAN changed from 192.168.0.1 to 192.168.4.1, to ensure it does not clash with common home router IP addresses.

* Battery percent can now be periodically shown instead of the batter icon in the status bar (change this option in settings->general)

* Gamma is now applied before the laser power setting, giving improved image output at lower laser power settings.
