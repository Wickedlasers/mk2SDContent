To Play The Halloween track "Thriller", you will need to obtain the Michael Jackson track "Thriller" which is from the single version (not the album version) of the track, and has a play time of around 5 minutes and 11 seconds to 5 min 13 seconds.
You will need to convert the mp3 file to 44.1KHz 16bit PCM WAV file format using the free Audacity software (available for Mac and Windows).
To do this in Audacity, load the MP3 (file->open, or drag n drop), then go to File->Export Audio, then choose 16 bit PCM stereo audio @ 44100Hz and save the file as "Thriller.wav".

Copy the converted .wav file into the /Lasercube/res/LaserShow/ folder, and ensure its name is "Thriller.wav", and the show will become available in the Halloween Laser Show list.

An example website where this can be downloaded:
https://audio.com/emilia-1843399209010982/audio/thriller-2003-edit

Note: ** User must have a license from the creator / publisher in order to own and use this audio track!!

Do not just rename the MP3 to WAV, it *MUST* be converted to the format described above in order to be played on the MK2.
